## 2. API1 — Login (POST /api/login)

### 2.1 Generate Step

**AI Prompting Strategy:** Multi-step prompting — separate prompts for each dimension:
1. **Prompt 1:** Domain partitions on `email` parameter
2. **Prompt 2:** Domain partitions on `password` parameter
3. **Prompt 3:** State transition test cases (account lockout machine)
4. **Prompt 4:** Security test cases (SEC-01 to SEC-07)
5. **Prompt 5:** Schema validation test cases

This step-by-step approach yielded **40 test cases** vs. a single prompt that would generate only ~15.
